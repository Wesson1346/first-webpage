# TXT 阅读器 — 产品设计文档（MVP）

> 版本：v0.2（MVP 规划；v0.1 起形态由网页版调整为桌面端）
> 日期：2026-09-01

## 1. 产品定位

一个轻量的**桌面端 TXT 电子书阅读器**：无需注册、无需联网，导入本地 TXT 文件即可舒适地阅读。

一句话描述：**能导入一本书，能舒服地读完它，下次打开接着读。**

## 2. 目标用户与场景

- 目标用户：以看 TXT 小说/网文为主的普通读者
- 核心场景：把电脑里的 TXT 书导入应用中阅读，中途关闭后再次打开能继续阅读

## 3. 设计原则

1. **阅读体验优先**：界面干净无干扰，正文排版舒适是第一优先级
2. **零门槛**：不需要注册和账号，不需要联网，书和进度全部保存在本地（IndexedDB）
3. **小步快跑**：MVP 只做主路径，其余功能进入后续迭代

## 4. MVP 功能范围

### 4.1 导入书籍
- 通过系统文件对话框或拖拽导入 `.txt` 文件
- 自动识别常见中文编码（UTF-8 / GBK），避免乱码

### 4.2 书架
- 列表展示已导入的书：书名、阅读进度（如「已读 35%」）、导入时间
- 点击书籍进入阅读
- 支持删除书籍

### 4.3 阅读器（核心）
- 分页展示正文，支持翻页：键盘方向键 / 点击屏幕左右区域
- 阅读时界面干净无干扰，行距、字号预设舒适
- **进度记忆**：自动保存阅读位置，下次打开同一本书自动定位（MVP 必须有）

### 4.4 阅读设置（最小集）
- 字号调整（3~4 档）
- 日间 / 夜间主题切换

## 5. 明确不做（Non-Goals）

MVP 不包含以下功能，避免范围膨胀：

- 其他格式：EPUB / PDF / MOBI
- 笔记类：书签、划线、笔记
- 书内搜索、目录跳转
- 云同步、多设备同步、账号体系
- 在线书城 / 资源获取
- TTS 朗读

## 6. 技术方案概要

| 项 | 选型 |
|---|---|
| 形态 | Electron 桌面应用（Windows 优先） |
| 构建与语言 | electron-vite + TypeScript |
| 数据存储 | IndexedDB（书籍内容、阅读进度、设置），渲染进程内读写 |
| 编码识别 | TextDecoder + 编码探测（UTF-8 优先，回退 GBK） |
| 交付 | electron-builder 打包 Windows 安装包 |

技术选型依据与模块设计详见 [技术方案.md](./技术方案.md)。

## 7. 后续迭代方向（Roadmap，仅备忘）

1. EPUB 格式支持（引入 epub.js）
2. 书内搜索与章节目录
3. 书签、划线笔记
4. 更多排版设置（行距、字体、边距）
5. 云同步与多设备

## 8. MVP 验收标准

- [ ] 能成功导入一本 UTF-8 和一本 GBK 编码的 TXT，无乱码
- [ ] 能流畅翻页阅读，翻页方式覆盖键盘与点击
- [ ] 关闭应用后重新打开，能自动回到上次阅读位置
- [ ] 字号与夜间模式切换即时生效，重启应用后保持
- [ ] 书架可进入、可删除书籍
